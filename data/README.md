# Your data workspace

This folder contains small synthetic examples and licence-approved data supplied with your labs. Each external dataset will include its source and reuse conditions.

Do not commit raw private data, personal information, passwords or large unapproved downloads. Store your exploratory imports in the location specified by your lab instructions.

If your lab supplies an offline snapshot, read [Apex fallback data](fallback-data.md) before loading it. Generated fallback files stay excluded from Git until a reviewed release is approved.
